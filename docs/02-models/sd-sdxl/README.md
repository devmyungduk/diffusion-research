## 이 장에서 배우는 것

- SD 1.5는 가볍고 빠르며 512×512 기준, SDXL은 무겁지만 품질이 좋고 1024×1024 기준입니다.
- 두 모델은 업그레이드 관계가 아니라 별개 모델이라, LoRA와 권장 해상도가 서로 호환되지 않습니다.
- SD 1.5 (가벼움/빠름) vs SDXL (고품질/무거움) 비교
- 내 PC 사양에 맞는 모델 선택 가이드
- SDXL 사용 시 해상도 최적화 팁

## SD 1.5 vs SDXL 비교

### 주요 차이점

| 항목 | SD 1.5 | SDXL |
|------|--------|------|
| **해상도** | 512×512 기본 | 1024×1024 기본 |
| **품질** | 기본 | 향상됨 |
| **VRAM** | 4GB+ | 8GB+ |
| **속도** | 빠름 | 느림 |
| **파일 크기** | ~2GB | ~6GB |
| **프롬프트 이해** | 보통 | 더 좋음 |

### 어떤 것을 선택할까?

**SD 1.5를 선택하세요:**
- VRAM이 4-6GB
- 빠른 생성 필요
- 512×512 크기로 충분

**SDXL을 선택하세요:**
- VRAM이 8GB+
- 고해상도 필요
- 더 나은 품질 원함

### 단계별 가이드

**1. 모델 로드**
```
노드: Load Checkpoint
파일: realisticVision_v60.safetensors (예시)
```

**2. 프롬프트 작성**
```
Positive: a beautiful landscape, high quality
Negative: blurry, low quality, distorted
```

**3. 이미지 크기 설정**
- SD 1.5: 512×512
- SDXL: 1024×1024

**4. 실행**
`Queue Prompt`를 누릅니다.

## 권장 설정

### SD 1.5 권장 설정

| 항목 | 값 | 이유 |
|------|-----|------|
| width × height | 512×512 | 최적 해상도 |
| steps | 25-30 | 품질/속도 균형 |
| cfg | 7-8 | 표준 |
| sampler | euler, dpmpp_2m | 안정적 |

### SDXL 권장 설정

처음 한 장을 만들 때는 [빠른 시작](../../00-getting-started/quick-start.md#4-첫-실행값-넣기)의 시작값(steps 25 · cfg 6.0)을 씁니다. 아래는 결과를 다듬는 단계에서 쓰는 범위입니다.

| 항목 | 값 | 이유 |
|------|-----|------|
| width × height | 1024×1024 | 최적 해상도 |
| steps | 30-40 | 고품질 |
| cfg | 7-9 | 표준 |
| sampler_name | dpmpp_2m | DPM++ 2M 갱신 방법 |
| scheduler | karras | sigma 배치 방식 |

### 해상도 가이드

**SD 1.5 권장 해상도:**

| 해상도 | 판단 |
|---|---|
| 512×512 | 최적 |
| 768×512 | 가로 |
| 512×768 | 세로 |
| 1024×1024 | 너무 큼. 반복 패턴이 생깁니다 |

**SDXL 권장 해상도:**

| 해상도 | 판단 |
|---|---|
| 1024×1024 | 최적 |
| 1216×832 | 가로 |
| 832×1216 | 세로 |
| 512×512 | 너무 작음. 디테일이 뭉개집니다 |

SDXL은 정해진 해상도 목록(버킷)으로 학습됐습니다. `1024×768`처럼 목록에 없는 크기는 목록 안의 값보다 불리합니다. 전체 목록은 [해상도 최적화](./resolution-optimization.md#3-권장-해상도-목록)에 있습니다.

## 문제 해결

### 이미지가 이상할 때

#### SD 1.5에서 1024×1024 생성 시
**문제:** 반복 패턴, 품질 저하
**해결:** 512×512로 생성 후 Upscale

#### SDXL에서 512×512 생성 시
**문제:** 디테일 부족, 흐릿함
**해결:** 1024×1024로 크기 변경

### 메모리 부족

**SD 1.5 (4GB VRAM):**
```
- 이미지 크기: 512×512로 제한
- Batch size: 1
- VAE: tiled VAE 사용
```

**SDXL (8GB VRAM):**
```
- 이미지 크기: 1024×1024로 제한
- Batch size: 1
- 그래도 부족하면 실행 플래그 조정
```

실행 플래그는 [문제 해결 가이드의 메모리 최적화](../../05-troubleshooting/README.md#2-메모리-관련-문제)를 참고하세요.

## 팁과 트릭

### SD 1.5 활용

**장점:**
- 빠른 반복 테스트
- 다양한 LoRA 지원
- 커뮤니티 모델 많음

**추천 용도:**
- 컨셉 스케치
- 빠른 프로토타입
- 애니메이션 스타일

### SDXL 활용

**장점:**
- 고품질 결과
- 복잡한 프롬프트 이해
- 사실적 이미지

**추천 용도:**
- 최종 결과물
- 사실적 이미지
- 고해상도 필요 시
