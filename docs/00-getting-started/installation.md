# ComfyUI 설치

> 운영체제와 GPU에 맞는 방법으로 ComfyUI를 설치하고 실행합니다. 모델 파일은 [모델 준비](models.md)에서 받습니다.

## 이 장에서 배우는 것

- 설치 방법 넷 중 무엇을 고를지는 운영체제와 GPU가 정합니다. 처음이라면 데스크톱 앱입니다.
- 커스텀 노드는 코드를 실행하므로 설치 전에 확인할 것이 있습니다.

<div class="guide-meta" markdown>
**대상** ComfyUI를 처음 설치하는 사용자 · **사전 이해** 없음 · **시간** 15분

**이럴 때 읽으세요** 설치 방법을 고르지 못했거나, 설치가 끝나지 않을 때.
</div>

ComfyUI는 자주 업데이트되고 설치 방법도 계속 바뀝니다. 이 문서는 방법을 고르는 기준과 전체 흐름을 설명하고, 실제 다운로드와 버전별 세부 절차는 항상 최신 상태인 공식 페이지를 따르도록 안내합니다.

- [공식 다운로드](https://comfy.org/download) — 운영체제별 설치 파일
- [공식 문서](https://docs.comfy.org) — 버전별 세부 절차

## 어떤 방법을 고를까

방법은 크게 넷입니다. 처음이라면 **데스크톱 앱**입니다. 나머지는 특별한 이유가 있을 때 사용합니다.

| 방법 | 지원 환경 | 설치 방식 |
|------|-----------|-----------|
| 데스크톱 앱 (Desktop) | Windows(NVIDIA) · macOS(Apple Silicon) | 설치 파일 실행, 자동 업데이트 |
| 포터블 (Portable) | Windows | 압축 해제 후 실행, 최신 커밋 |
| [수동 설치 (Manual)](https://docs.comfy.org/installation/manual_install) | 모든 OS · 모든 GPU | git으로 직접 설치, 버전 직접 지정 |
| 클라우드 (Cloud) | 브라우저 | 설치 없음, 유료 |

Linux용 Desktop 사전 빌드 패키지는 현재 제공되지 않으므로 Linux에서는 수동 설치를 선택합니다. Windows의 AMD·Intel GPU도 Desktop 대신 수동 설치를 사용합니다. 절차는 [공식 수동 설치 안내](https://docs.comfy.org/installation/manual_install)에 운영체제와 GPU별로 나뉘어 있습니다. GPU가 없으면 CPU 모드로 실행할 수 있지만 한 장에 수 분에서 수십 분이 걸려 클라우드가 현실적인 대안일 수 있습니다.

## 준비물

- **컴퓨터**: Windows, macOS(Apple Silicon), Linux 중 하나
- **그래픽카드(GPU)**: 권장. NVIDIA·AMD·Intel·Apple Silicon의 지원 범위와 설치 절차가 서로 다릅니다. 자신의 운영체제와 GPU 조합을 [공식 시스템 요구사항](https://docs.comfy.org/installation/system_requirements)에서 먼저 확인하세요. VRAM이 클수록 큰 모델을 올리고 batch_size를 늘릴 여유가 생깁니다.
- **저장 공간**: ComfyUI 자체는 가볍지만 모델 파일이 큽니다(하나에 수 GB). 넉넉한 드라이브를 준비하세요.
- **모델 파일 1개**: 설치 후 이미지를 생성하려면 체크포인트 모델이 최소 하나 필요합니다. 받는 방법은 [모델 준비](models.md)에 있습니다.

## 데스크톱 앱으로 설치하기

터미널을 사용하지 않는 경로입니다.

1. [공식 다운로드 페이지](https://comfy.org/download)에서 자신의 운영체제용 설치 파일을 내려받습니다.
2. 설치 파일을 실행합니다.
   - Windows: NVIDIA GPU용 설치 파일(.exe)을 실행하고 시작 메뉴나 바탕화면 아이콘으로 엽니다.
   - macOS: Apple Silicon용 .dmg를 열고 앱을 응용 프로그램 폴더로 드래그한 뒤 실행합니다.
3. 앱을 처음 열면 첫 설정을 자동으로 안내합니다. 화면 지시를 따르면 ComfyUI 환경(파이썬·GPU 구성 포함)이 자동으로 준비됩니다.
4. 준비가 끝나면 노드 편집 화면이 열립니다. 여기까지 왔으면 설치는 끝입니다.

데스크톱 앱은 여러 개의 독립 설치를 나란히 두고 버전을 따로 관리할 수 있으며, 앱 자체가 자동으로 최신 상태를 유지합니다.

## 커스텀 노드 관리자와 안전한 확장 설치

현재 Desktop과 다수의 최신 설치 방식에는 **ComfyUI-Manager**가 포함되어 있으므로 먼저 Manager가 이미 보이는지 확인하세요. 없다면 [공식 Manager 설치 안내](https://docs.comfy.org/manager/install)를 따릅니다.

커스텀 노드는 Python 코드와 추가 의존성을 실행할 수 있습니다.

지금 사용하는 노드가 기본 노드인지 커스텀 노드인지는 화면에서 구분합니다. `Settings → LiteGraph (Canvas) → Node → Node Source Badge Mode`를 `Show all`로 두면 노드 제목 옆에 출처 배지가 붙고, ComfyUI 기본 노드에는 여우 아이콘이 표시됩니다.

??? warning "설치 전 지킬 원칙 여섯 가지 — 첫 설치 뒤에 읽어도 됩니다"

    1. Comfy Registry에 등록되고 검증 상태를 확인할 수 있는 노드를 우선합니다.
    2. 설치 전에 저장소 주소·관리 주체·README·최근 업데이트·필요 권한과 의존성을 확인합니다.
    3. `Install missing nodes`를 한꺼번에 실행하기 전에 각 노드가 지금 필요한지 확인합니다.
    4. 설치·업데이트 전 Manager snapshot을 만들고, 프로젝트별로 사용한 노드 버전을 기록합니다.
    5. 설치 뒤 문제가 생기면 모든 커스텀 노드를 비활성화해 재현한 다음 하나씩 다시 켭니다.
    6. 외부에서 접속 가능한 ComfyUI 서버에서는 설치·업데이트 기능을 노출하지 않습니다.

    출처가 불분명한 저장소를 수동으로 내려받거나 Manager의 보안 수준을 낮추는 방법은 입문 절차로 권장하지 않습니다. 자세한 기준은 [공식 커스텀 노드 설치·보안 안내](https://docs.comfy.org/installation/install_custom_node)를 참고하세요.

??? warning "설치가 안 될 때 — 증상별 확인"
    | 증상 | 확인 |
    |------|------|
    | 브라우저에 "Connection refused" | ComfyUI 서버가 실행 중인지, 네트워크 포트(기본 8188)가 방화벽에 막히지 않았는지 확인 |
    | 포터블 버전에서 python-embed 오류 | 포터블 대신 데스크톱 앱이나 수동 설치 사용 |
    | 이미지가 생성되지만 이상함 | 모델 파일이 손상됐을 수 있음. 다시 내려받고 다른 모델로 교차 확인 |
    | 커스텀 노드 설치 실패 | 인터넷 연결·Registry 등록 상태·ComfyUI/노드 호환 버전을 확인. 수동 설치 전 공식 안내와 저장소 신뢰성을 검토 |

    그 밖의 문제는 [문제 해결 가이드](../05-troubleshooting/README.md)와 공식 문서를 참고하세요.

## 완료 기준

두 가지를 모두 만족했다면 이 장을 끝냈습니다.

- 자신의 운영체제와 GPU에 맞는 설치 방법을 골라 ComfyUI를 실행했고, 노드 편집 화면이 열렸다.
- 지금 사용하는 노드가 기본 노드인지 커스텀 노드인지 화면에서 구분할 수 있다.
