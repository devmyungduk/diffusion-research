# ComfyUI 설치

> 디자이너·아티스트를 포함해 처음 접하는 분을 기준으로, 가장 쉬운 방법부터 안내합니다.

ComfyUI는 자주 업데이트되고 설치 방법도 계속 바뀝니다. 이 문서는 방법을 고르는 기준과 전체 흐름을 설명하고, 실제 다운로드와 버전별 세부 절차는 항상 최신 상태인 공식 페이지를 따르도록 안내합니다.

- 공식 다운로드: https://comfy.org/download
- 공식 문서: https://docs.comfy.org

## 어떤 방법을 고를까

방법은 크게 넷입니다. 처음이라면 **데스크톱 앱**을 고르세요. 나머지는 특별한 이유가 있을 때만 선택합니다.

| 방법 | 지원 환경 | 설치 방식 |
|------|-----------|-----------|
| 데스크톱 앱 (Desktop) | Windows(NVIDIA) · macOS(Apple Silicon) | 설치 파일 실행, 자동 업데이트 |
| 포터블 (Portable) | Windows | 압축 해제 후 실행, 최신 커밋 |
| 수동 설치 (Manual) | 모든 OS · 모든 GPU | git으로 직접 설치, 버전 직접 지정 |
| 클라우드 (Cloud) | 브라우저 | 설치 없음, 유료 |

Linux용 Desktop 사전 빌드 패키지는 현재 제공되지 않으므로 Linux에서는 수동 설치를 선택합니다. Windows의 AMD·Intel GPU도 Desktop 대신 해당 하드웨어용 수동 설치 안내를 따릅니다. GPU가 없으면 CPU 모드로 실행할 수 있지만 이미지 생성 속도가 매우 느려 클라우드가 현실적인 대안일 수 있습니다.

## 준비물

- **컴퓨터**: Windows, macOS(Apple Silicon), Linux 중 하나
- **그래픽카드(GPU)**: 권장. NVIDIA·AMD·Intel·Apple Silicon의 지원 범위와 설치 절차가 서로 다릅니다. 자신의 운영체제와 GPU 조합을 [공식 시스템 요구사항](https://docs.comfy.org/installation/system_requirements)에서 먼저 확인하세요. VRAM이 클수록 큰 모델과 배치를 다루기 쉽습니다.
- **저장 공간**: ComfyUI 자체는 가볍지만 모델 파일이 큽니다(하나에 수 GB). 넉넉한 드라이브를 준비하세요.
- **모델 파일 1개**: 설치 후 이미지를 생성하려면 체크포인트 모델이 최소 하나 필요합니다(아래 참고).

## 데스크톱 앱으로 설치하기

가장 쉬운 경로입니다. 터미널을 쓰지 않습니다.

1. https://comfy.org/download 에서 자신의 운영체제용 설치 파일을 내려받습니다.
2. 설치 파일을 실행합니다.
   - Windows: NVIDIA GPU용 설치 파일(.exe)을 실행하고 시작 메뉴나 바탕화면 아이콘으로 엽니다.
   - macOS: Apple Silicon용 .dmg를 열고 앱을 응용 프로그램 폴더로 드래그한 뒤 실행합니다.
3. 앱을 처음 열면 첫 설정을 자동으로 안내합니다. 화면 지시를 따르면 ComfyUI 환경(파이썬·GPU 구성 포함)이 자동으로 준비됩니다.
4. 준비가 끝나면 노드 편집 화면이 열립니다. 여기까지 왔으면 설치는 끝입니다.

데스크톱 앱은 여러 개의 독립 설치를 나란히 두고 버전을 따로 관리할 수 있으며, 앱 자체가 자동으로 최신 상태를 유지합니다.

## 모델 파일 넣기

ComfyUI를 실행해도 모델이 없으면 이미지를 만들 수 없습니다. 아래 순서대로 진행합니다.

### 1. 모델 폴더 열기

모델은 `ComfyUI/models/` 아래에 둡니다. 이 폴더의 실제 위치는 설치 방식마다 다릅니다.

- **데스크톱 앱**: 앱 메뉴에서 **Help → Open Folder → Open Model Folder**를 선택하면 해당 폴더가 바로 열립니다.
- **포터블·수동 설치**: 압축을 풀거나 `git clone`한 `ComfyUI` 폴더 안의 `models`입니다.

### 2. 모델 내려받기

모델은 [Hugging Face](https://huggingface.co)나 [Civitai](https://civitai.com)에서 내려받습니다. 처음이라면 SD 1.5 또는 SDXL 체크포인트 하나로 시작하세요. 파일 하나에 2~7GB 정도입니다.

### 3. 종류별 폴더에 넣기

| 폴더 | 넣을 파일 |
|------|------|
| `checkpoints/` | SD 1.5, SDXL 체크포인트 |
| `vae/` | 별도 VAE 파일 |
| `loras/` | LoRA 파일 |
| `controlnet/` | ControlNet 모델 |
| `text_encoders/` | CLIP / T5 등 텍스트 인코더 (Flux 등) |
| `diffusion_models/` | Flux 등 diffusion 모델 본체 |

!!! warning "확장자로는 종류를 구분할 수 없습니다"
    체크포인트·LoRA·VAE·텍스트 인코더·업스케일러가 **모두 `.safetensors`** 확장자를 씁니다. 잘못된 폴더에 넣는 실수는 대부분 여기서 생깁니다. 파일 이름만 보고 판단하지 말고, 내려받은 페이지에 적힌 모델 종류를 확인한 뒤 넣으세요.

> 구버전 ComfyUI나 오래된 튜토리얼은 `clip/`·`unet/`이라는 이름을 씁니다. 현재 표준은 `text_encoders/`·`diffusion_models/`이며, ComfyUI는 구 폴더도 계속 읽으니 로더 목록이 비어 보이면 파일이 반대쪽 폴더에 있는지 확인하세요. (GGUF 파일은 예외적으로 `unet/`을 씁니다.)

### 4. ComfyUI에 인식시키기

ComfyUI가 실행 중인 상태에서 파일을 넣었다면 목록이 자동으로 갱신되지 않습니다. 브라우저 화면에서 **`r` 키를 눌러 노드 정의를 새로 읽거나**, ComfyUI를 재시작합니다.

### 5. 제대로 들어갔는지 확인하기

`Load Checkpoint` 노드를 하나 추가하고 `ckpt_name` 목록을 엽니다. 방금 넣은 파일 이름이 보이면 성공입니다.

목록이 비어 있다면 순서대로 확인합니다.

1. 4번의 새로고침을 했는지
2. 파일이 `checkpoints/`가 아닌 다른 폴더에 들어갔는지
3. 열어 본 `models` 폴더가 실제로 ComfyUI가 쓰는 경로인지 (설치를 여러 개 두면 헷갈립니다)

### 모델을 다른 드라이브에 두기

모델 파일이 커서 설치 드라이브가 부족하면, `models` 폴더를 옮기지 않고 **검색 경로를 추가**할 수 있습니다. ComfyUI 폴더의 `extra_model_paths.yaml.example`을 `extra_model_paths.yaml`로 복사한 뒤 경로를 적으면, 다른 드라이브나 다른 프로그램의 모델 폴더를 함께 읽습니다. 설정 후에는 ComfyUI를 재시작합니다.

Flux 같은 최신 모델은 파일이 여러 개로 나뉘어 각각 다른 폴더에 들어갑니다. 자세한 배치는 [Flux 가이드](../02-models/flux/README.md)에서 다룹니다.

## 커스텀 노드 관리자와 안전한 확장 설치

ComfyUI의 강점은 커뮤니티가 만든 확장(커스텀 노드)입니다. 현재 Desktop과 다수의 최신 설치 방식에는 **ComfyUI Manager**가 포함되어 있으므로 먼저 Manager가 이미 보이는지 확인하세요. 없다면 [공식 Manager 설치 안내](https://docs.comfy.org/manager/install)를 따릅니다.

커스텀 노드는 Python 코드와 추가 의존성을 실행할 수 있습니다.

??? warning "설치 전 지킬 원칙 여섯 가지 — 첫 설치 뒤에 읽어도 됩니다"

    1. Comfy Registry에 등록되고 검증 상태를 확인할 수 있는 노드를 우선합니다.
    2. 설치 전에 저장소 주소·관리 주체·README·최근 업데이트·필요 권한과 의존성을 확인합니다.
    3. `Install missing nodes`를 한꺼번에 실행하기 전에 각 노드가 정말 필요한지 확인합니다.
    4. 설치·업데이트 전 Manager snapshot을 만들고, 프로젝트별로 사용한 노드 버전을 기록합니다.
    5. 설치 뒤 문제가 생기면 모든 커스텀 노드를 비활성화해 재현한 다음 하나씩 다시 켭니다.
    6. 외부에서 접속 가능한 ComfyUI 서버에서는 설치·업데이트 기능을 노출하지 않습니다.

    출처가 불분명한 저장소를 수동으로 내려받거나 Manager의 보안 수준을 낮추는 방법은 입문 절차로 권장하지 않습니다. 자세한 기준은 [공식 커스텀 노드 설치·보안 안내](https://docs.comfy.org/installation/install_custom_node)를 참고하세요.

??? warning "설치가 안 될 때 — 증상별 확인"
    | 증상 | 확인 |
    |------|------|
    | 브라우저에 "Connection refused" | ComfyUI 서버가 실행 중인지, 포트(기본 8188)가 방화벽에 막히지 않았는지 확인 |
    | 포터블 버전에서 python-embed 오류 | 포터블 대신 데스크톱 앱이나 수동 설치 사용 |
    | 이미지가 생성되지만 이상함 | 모델 파일이 손상됐을 수 있음. 다시 내려받고 다른 모델로 교차 확인 |
    | 커스텀 노드 설치 실패 | 인터넷 연결·Registry 등록 상태·ComfyUI/노드 호환 버전을 확인. 수동 설치 전 공식 안내와 저장소 신뢰성을 검토 |

    그 밖의 문제는 [문제 해결 가이드](../05-troubleshooting/README.md)와 공식 문서를 참고하세요.
