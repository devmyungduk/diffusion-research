# 노드 다루기

> 노드를 추가하고 복사하고, 지우지 않은 채 잠시 빼서 결과를 비교합니다.

## 이 장에서 배우는 것

- 노드를 추가하는 방법은 세 가지이고, 포트에서 끌어 놓는 방법은 타입이 맞는 노드만 후보로 표시합니다.
- `Ctrl + B`로 노드를 지우지 않고 통과시킬 수 있습니다. 노드 하나를 뺐을 때 결과가 어떻게 달라지는지 확인하는 수단입니다.

<div class="guide-meta" markdown>
**대상** [빠른 시작](quick-start.md)에서 워크플로우를 한 번 만들어 본 사용자 · **사전 이해** [캔버스 다루기](canvas-basics.md)의 캔버스 조작 · **시간** 15분

**이럴 때 읽으세요** 노드를 하나 빼고 결과를 보고 싶은데 지우기는 싫을 때, 또는 연결선이 엉켜 화면을 못 읽겠을 때.
</div>

## 1. 노드 추가

세 가지 방법이 있고 상황에 따라 용도가 다릅니다.

| 방법 | 조작 | 특징 |
|---|---|---|
| 검색 | 캔버스 **더블클릭** | 이름을 알 때 가장 빠릅니다 |
| 메뉴 | 캔버스 **우클릭 → Add Node** | 분류를 훑어보며 고를 때 |
| 포트에서 끌기 | 포트에서 빈 곳으로 **드래그 후 놓기** | 그 타입에 연결되는 노드만 후보로 나옵니다 |

세 번째 방법이 연결 실수를 줄입니다. `KSampler`의 `LATENT` 출력에서 끌어 놓으면 `LATENT`를 받는 노드만 목록에 나오므로, 타입이 안 맞아 선이 붙지 않는 상황 자체가 생기지 않습니다.

## 2. 선택·복사·삭제

| 조작 | 동작 |
|---|---|
| 클릭 | 노드 하나 선택 |
| `Ctrl + A` (macOS `⌘ + A`) | 전체 선택 |
| `Delete` 또는 `Backspace` | 선택한 노드 삭제 |
| `Ctrl + C` → `Ctrl + V` | 복사·붙여넣기. **연결은 따라오지 않습니다** |
| `Ctrl + C` → `Ctrl + Shift + V` | 복사·붙여넣기. **입력 연결까지 유지** |

붙여넣기 두 가지의 차이가 실수를 만드는 지점입니다. `CLIP Text Encode`를 복사해 Negative를 만들 때 `Ctrl + V`를 사용하면 `clip` 입력이 비어 실행이 막히고, `Ctrl + Shift + V`를 사용하면 같은 `Load Checkpoint`의 CLIP에 이미 연결된 채로 붙습니다.

## 3. Bypass와 Mute

노드를 지우지 않고 잠시 빼는 방법입니다. **두 가지가 다르게 동작합니다.**

| 조작 | 이름 | 그 노드의 동작 | 뒤쪽 노드 |
|---|---|---|---|
| `Ctrl + B` (macOS `⌘ + B`) | Bypass | 계산을 건너뛰고 **입력을 그대로 출력으로 넘김** | 계속 실행됩니다 |
| `Ctrl + M` (macOS `⌘ + M`) | Mute | 출력을 내보내지 않음 | 입력이 끊겨 실행되지 않습니다 |

`Load LoRA`를 `Ctrl + B`로 Bypass하면 MODEL과 CLIP이 그대로 통과해 LoRA만 빠진 결과가 나옵니다. 같은 노드를 `Ctrl + M`으로 Mute하면 그 뒤의 KSampler가 입력을 받지 못해 워크플로우가 실행되지 않습니다.

!!! tip "한 변수 실험에 사용하는 기능입니다"
    이 학습서는 Seed를 고정하고 값 하나만 바꿔 비교합니다. **노드 하나를 뺀 결과**와 비교하고 싶을 때는 노드를 지웠다 다시 만들지 말고 `Ctrl + B`를 사용합니다. 연결이 그대로 남아 있어 되돌리기도 같은 키 하나입니다.

## 4. Reroute

연결선이 다른 노드 위를 지나가 화면을 읽기 어려울 때, 선 중간에 경유점을 놓아 우회시킬 수 있습니다. 노드 검색에서 `Reroute`를 추가하고 선을 이 노드로 통과시킵니다.

`Reroute`는 데이터를 바꾸지 않습니다. 결과에 영향을 주지 않고 배치만 정리합니다.

## 5. 위젯과 포트 바꾸기

노드 안에서 값을 넣는 칸이 위젯이고, 선으로 잇는 자리가 포트입니다. 위젯을 우클릭하면 포트로 바꿀 수 있습니다.

바꾸면 그 값을 다른 노드에서 받아올 수 있습니다. 예를 들어 두 KSampler가 같은 `seed`를 사용하게 하려면, 양쪽의 `seed` 위젯을 포트로 바꾸고 하나의 값 노드에서 두 곳으로 연결합니다. 한 곳만 고치면 둘 다 따라옵니다.

## 6. 여러 노드를 한 덩어리로 — Group과 Subgraph

노드가 늘어나 화면을 읽기 어려울 때 사용하는 방법이 두 가지입니다. 하나는 테두리로 묶는 것이고, 하나는 노드 하나로 접는 것입니다.

| | Group | Subgraph |
|---|---|---|
| 하는 일 | 노드들을 테두리로 묶어 함께 옮깁니다 | 노드들을 노드 하나로 접습니다 |
| 화면 | 노드가 그대로 다 보입니다 | 안이 감춰지고 입력·출력만 보입니다 |
| 만들기 | 노드를 선택하고 우클릭 → `Add Group For Selected Nodes` | 노드를 선택하고 우클릭 → `Convert to Subgraph` |

**Group** — 캔버스 우클릭 `Add Group`으로 빈 그룹을 만들고 그 안으로 노드를 옮겨도 됩니다. 그룹 제목을 잡고 끌면 안의 노드가 함께 움직입니다. `Fit Group To Contents`는 테두리를 안의 노드 크기로 조정합니다.

**Subgraph** — 접힌 노드를 더블클릭하면 안으로 들어가고, `Exit Subgraph`로 나옵니다. 안에서 우클릭한 입력·출력 자리는 이름을 바꾸거나 지울 수 있습니다. `Unpack Subgraph`를 사용하면 원래 노드들로 되돌아갑니다. Subgraph 노드도 일반 노드처럼 `Ctrl + B`로 Bypass할 수 있습니다.

Subgraph는 ComfyUI 프론트엔드 1.24.3 이상에서 동작합니다. 메뉴에 없으면 ComfyUI를 갱신합니다.

| 조작 | 동작 |
|---|---|
| `Alt + C` (macOS `⌥ + C`) | 선택한 노드를 접거나 폅니다 |
| `P` | 선택한 항목을 고정하거나 풉니다. 고정하면 끌어도 움직이지 않습니다 |

## 7. 화면에 설명 남기기 — Note와 색상

`Note`는 캔버스에 글을 적어 두는 노드입니다. 노드 검색에서 `Note`를 추가하고 상자 안에 텍스트를 입력합니다. 입력·출력 포트가 없어 실행에 참여하지 않으므로 결과가 달라지지 않습니다. 마크다운 표기를 사용하려면 `MarkdownNote`를 추가합니다.

어떤 값을 왜 그렇게 두었는지 여기에 적으면 워크플로우 `.json` 안에 함께 저장됩니다. 파일 밖에 따로 남기는 기록 양식은 [저장과 재현](save-and-reproduce.md#재현-기록-남기기)에 있습니다.

노드를 우클릭하고 `Colors`를 고르면 노드 색이 바뀝니다. ControlNet 관련 노드처럼 한 묶음으로 읽어야 하는 노드에 같은 색을 지정합니다.

## 8. 한 변수 실험 — Bypass와 Mute 비교

[빠른 시작](quick-start.md)에서 만든 7노드 워크플로우를 엽니다. Seed를 고정하고 아래를 차례로 실행합니다.

| 실행 | 조작 | 관찰할 것 |
|---|---|---|
| A | 그대로 실행 | 기준 이미지 |
| B | `Save Image`를 선택하고 `Ctrl + M` | 실행이 되는가, 결과가 나오는가 |
| C | B를 되돌리고 `CLIP Text Encode`(Negative)를 선택해 `Ctrl + B` | 실행되는가. A와 결과가 어떻게 다른가 |

!!! question "관찰 질문"
    C에서 Negative를 Bypass했는데 워크플로우는 멈추지 않았습니다. Bypass가 입력을 출력으로 넘긴다는 점에서 그 이유를 설명할 수 있나요?

## 9. 문제 해결

| 증상 | 확인 순서 |
|---|---|
| 복사한 노드의 입력이 비어 있음 | `Ctrl + V` 대신 `Ctrl + Shift + V`를 사용했는지 확인 |
| 노드를 뺐더니 실행이 멈춤 | Mute(`Ctrl + M`)가 아니라 Bypass(`Ctrl + B`)인지 확인 |
| Bypass했는데 결과가 그대로 | 그 노드가 원래 값을 바꾸지 않는 자리였을 수 있습니다. 출력 포트가 다음 노드로 실제 연결됐는지 확인 |
| 포트에서 끌어 놓았는데 후보가 없음 | 그 타입을 받는 노드가 설치돼 있지 않은 경우입니다. [설치 가이드](installation.md)의 커스텀 노드 항목 확인 |
| 단축키가 동작하지 않음 | `Settings → Keybinding`에서 현재 값을 확인 |

## 완료 기준

네 가지를 모두 만족했다면 이 장을 끝냈습니다.

- 노드를 세 가지 방법으로 각각 추가해 봤다.
- `Ctrl + V`와 `Ctrl + Shift + V`의 차이를 확인했다.
- Bypass와 Mute가 뒤쪽 노드에 미치는 영향의 차이를 설명할 수 있다.
- 노드를 지우지 않고 뺀 결과를 기준 이미지와 비교했다.
