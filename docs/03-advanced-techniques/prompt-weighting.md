# 프롬프트 가중치

> 프롬프트 안에서 특정 단어의 강도만 조절하는 방법입니다. 모델이나 노드를 추가하지 않고 텍스트만으로 제어합니다.

## 이 장에서 배우는 것

- `(개념:1.5)` 형식으로 프롬프트 안 특정 단어의 비중만 올리거나 내립니다.
- `cfg`는 프롬프트 전체를, 가중치는 프롬프트 안 단어 사이의 비중을 조절합니다.
- `(개념:가중치)` 문법과 값의 범위
- 값을 올렸을 때와 내렸을 때의 실제 차이
- 여러 개념의 강도를 상대적으로 맞추는 방법

<div class="guide-meta" markdown>
**대상** 프롬프트에 단어를 넣었는데 반영이 약하거나 과한 사용자 · **사전 이해** CLIP Text Encode 노드 사용 경험 · **시간** 10분

**이럴 때 읽으세요** 적어 둔 단어가 결과에 약하게 나오거나 지나치게 강하게 나올 때.
</div>

## 1. 무엇을 조절하는가

프롬프트 가중치는 **특정 개념의 중요도**를 바꿉니다. 단어를 더 넣거나 빼지 않고, 이미 적은 단어의 반영 강도만 조절합니다.

`CLIP Text Encode` 노드의 텍스트에 아래 형식으로 적습니다.

```text
(개념:가중치)

예시: (ink and painting:1.5)
```

| 요소 | 설명 | 예시 |
|------|------|------|
| 개념 | 강조할 단어나 스타일 | `ink and painting` |
| `:` | 구분자 | `:` |
| 가중치 | 강도 | `1.5` |

`cfg`와 혼동하지 마세요. `cfg`는 **프롬프트 전체**를 얼마나 강하게 따를지 정하고, 가중치는 **프롬프트 안에서 단어 사이의 비중**을 정합니다.

## 2. 값의 범위

| 가중치 | 결과 |
|---:|---|
| 0.1~0.5 | 개념이 거의 반영되지 않습니다 |
| 0.8 | 은은하게 반영됩니다 |
| 1.0 | 기본값입니다. 아무것도 적지 않은 상태와 같습니다 |
| 1.5 | 명확하게 강조됩니다 |
| 2.0 | 강하게 강조됩니다. 실용적인 상한선입니다 |
| 2.5 이상 | 형태가 무너지거나 색이 튀는 일이 잦습니다 |

문법이 값을 제한하지는 않습니다. 2.0은 규격상의 최댓값이 아니라 **결과가 안정적으로 유지되는 상한**입니다.

## 3. 실전 예시

**스타일 강조**
```text
(ink and painting:1.5), (watercolor:0.8), portrait
```
잉크 페인팅을 주된 스타일로 삼고, 수채화 느낌은 약하게 섞고, 인물 초상화는 기본 강도로 둡니다.

**여러 개념의 비중 조절**
```text
(masterpiece:1.3), (detailed:1.2), (photo realistic:1.5), portrait of a woman
```
품질·디테일·사실성을 각각 다른 강도로 지정합니다. 세 값의 크기 관계가 결과의 성격을 정합니다.

**색상 제어**
```text
(red apple:1.5), (blue background:1.3), on a wooden table
```
사과 색을 가장 강하게, 배경색을 그다음으로, 테이블은 기본 강도로 둡니다.

## 4. 작동 방식

가중치는 CLIP이 텍스트를 숫자로 바꿀 때 해당 토큰의 비중에 반영됩니다. `(ink and painting:1.5)`라고 적으면 그 개념의 임베딩 기여도가 커지고, 샘플링 과정에서 그 방향으로 더 강하게 끌립니다.

따라서 **프롬프트에 없는 개념은 가중치로 만들어낼 수 없습니다.** 원하는 요소가 아예 나오지 않는다면 가중치를 올리기 전에 단어를 먼저 추가하세요.

## 5. 주의사항

**과도한 값을 피합니다.** `(red:3.0)`은 색이 왜곡되고 아티팩트가 생깁니다. 같은 목적이면 `(red:1.5)` 쪽이 안정적입니다.

**모든 단어에 값을 붙이지 않습니다.** 전부 2.0으로 올리면 상대적 비중이 도로 같아져 아무 효과가 없습니다. 강조할 것만 지정합니다.

**한 번에 하나씩 조정합니다.** `1.0 → 1.2 → 1.5 → 1.3`처럼 단계적으로 옮기며 값을 찾습니다. Seed를 고정하지 않으면 가중치 때문에 바뀐 것인지 구분할 수 없습니다.

## 완료 기준

세 가지를 모두 만족했다면 이 장을 끝냈습니다.

- Seed를 고정하고 한 단어의 가중치만 바꿔 결과를 비교했다.
- 가중치와 `cfg`가 각각 무엇을 조절하는지 구분할 수 있다.
- 프롬프트에 없는 개념은 가중치로 만들어낼 수 없다는 점을 안다.
